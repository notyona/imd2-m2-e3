# M2-E3 : simplifier un CSS grâce à l'héritage

Le site est terminé et fonctionne. Son CSS, lui, répète les mêmes déclarations partout.

## Démarrer le projet

Dans le terminal de VS Code, à la racine du projet :

```bash
npm install
npm start
```

## Ce qu'il y a à faire

Dans `src/style.css`, supprimez les déclarations répétées en les remontant là où elles peuvent être héritées. Le rendu doit rester identique à la maquette Figma.
